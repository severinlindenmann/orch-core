Agents work between the gates and stop at each one. Only a person can open a gate: you sign in a physical way, with your fingerprint or your phone. An agent can type any command, but it can’t put a finger on the sensor. Questions park the work with a recommended answer until you reply.

AI Factory
Lights on. The factory runs the tickets, you watch the board and can step in at any gate. Every approval it gives is marked “via the charter”.
Dark AI Factory
Lights off. One signed request runs end to end, from requirements to delivery, with restricted permissions. You sign it in, and you can stop it before it ships.
Never auto-approved: a code review gate, if your workspace turns one on. When the budget is reached, no new tickets start.
Checklist and evidence

Trust the evidence, not the summary

What an agent says
“Done ✓ All tests green, everything works as requested. Ready to ship.”

A summary is a claim. Agents like to report success. Half of it may be missing, and you only find out later.

The checklist is agreed before the work starts (gate 1). The agent ticks off each criterion only with evidence: a test run, a row count, a report, a screenshot, a link to the change. Your verdict signs the evidence and exactly one commit, and a new commit voids it.
