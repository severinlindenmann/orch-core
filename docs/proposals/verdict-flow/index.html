4

New widgets for reviewing deliverables

The 28 core widgets cover code work well (diff, tests, gates, deploy). Content and design tickets produce pages, images and documents, and that is where the review stalls today. Four additions:

gallery review

Many outputs per AC (10 posts, 3 landing drafts, a visual library). Grid of thumbnails, click opens a lightbox with ← → and the label. HTML/URL artifacts get a server-side snapshot.

{"type": "gallery", "ac": 1, "columns": 4,
 "items": [{"label": "Post 01", "artifact": "post-01.png"},
           {"label": "Landing A", "artifact": "landing-a.html", "as": "snapshot"}]}

preview review

Today a local HTML artifact or a claude.ai artifact is a bare link (screenshot 3). Embed it in a sandboxed iframe with viewport toggles; external URLs fall back to a snapshot plus the link.

artifacts/INT-0004/landing-b/index.html3901280↗
{"type": "preview", "artifact": "landing-b/index.html",
 "viewports": [390, 1280], "height": 480, "sandbox": true}

review verify

A verdict per criterion instead of one yes/no for the whole ticket. Each flagged AC pre-fills the Send back composer (frame 3), so partial acceptance is one step.
