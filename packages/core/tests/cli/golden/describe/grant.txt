ok describe grant
Issue a standing grant for agents; the secret is printed once, on your terminal.
usage: orch grant [--hours N] [--days N] [--scope all|workable] [--verbs VERBS] [--label TEXT] [--extend GRANT] [--runner] [--dry-run]
who: human · emits: grant.issued,grant.revoked
pre: workspace_exists role_allows user_presence text_clean
args:
  --hours N  length in whole hours (1 to 168)
  --days N  length in whole days (1 to 7); instead of --hours
  --scope SCOPE  what it covers (all|workable) [default workable]
  --verbs VERBS  agent, or operation names comma separated [default agent]
  --label TEXT  short label
  --extend GRANT  revoke this runner grant of yours together with the new one (with --runner)
  --runner  hand the secret to the runner here instead of showing it (at most the grant_hours setting)
  --dry-run  say what would happen, append nothing
errors:
  custody.no_key (exit 3): orch setup sets up your device key | fix: orch help
  custody.no_prompt (exit 3): run this command yourself, in your own terminal | fix: orch help
  custody.wrong_passphrase (exit 3): run the command again and type your passphrase | fix: orch help
  human_only (exit 3): orch ask or orch wait | fix: orch describe ask
  role.denied (exit 3): ask an owner or maintainer | fix: orch status
  sign.cancelled (exit 3): run the command again to review | fix: 
  tty.required (exit 3): run the command in your terminal | fix: 
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
  parse.text (exit 6): orch describe grant
  members.stale (exit 9 retry): retry; the person re-signs | fix: orch status
out: ok grant.issued[ {grant}][ until {until_local}] / next: {next}
