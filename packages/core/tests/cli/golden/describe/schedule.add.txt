ok describe schedule.add
Schedule automatic agent sessions on this ticket for up to 30 days.
usage: orch schedule add [REF] [--target existing|new] [--title TITLE] --at AT [--every day|week|month] [--tz TZ] [--weekdays WEEKDAYS] [--day DAY] [--brief BRIEF] [--brief-file PATH] [--until UNTIL] [--run-hours RUN_HOURS] [--dry-run]
who: human · emits: schedule.set
args:
  REF  ticket REF; required for target existing
  --target TARGET  existing or new ticket (existing|new) [default existing]
  --title TITLE  literal title for each new ticket
  --at AT  once: YYYY-MM-DD HH:MM; recurring: HH:MM (required)
  --every EVERY  day, week or month (day|week|month)
  --tz TZ  IANA timezone; default UTC
  --weekdays WEEKDAYS  comma-separated weekdays 0..6, Monday=0
  --day DAY  monthly day; clamps to the last day of shorter months
  --brief BRIEF  the brief as text
  --brief-file PATH  read the text from PATH, or - for stdin
  --until UNTIL  end instant; defaults to 30 days
  --run-hours RUN_HOURS  maximum hours per run; default 8
  --dry-run  say what would happen, append nothing
errors:
  ambiguous_ref (exit 2): name the ticket REF, for example DEMO-0043 | fix: orch status
  not_found (exit 2): orch list
  addon.off (exit 3): tell the person; do not work around it | fix: orch addon list
  custody.no_key (exit 3): orch setup sets up your device key | fix: orch help
  custody.no_prompt (exit 3): run this command yourself, in your own terminal | fix: orch help
  custody.wrong_passphrase (exit 3): run the command again and type your passphrase | fix: orch help
  human_only (exit 3): orch ask or orch wait | fix: orch describe ask
  schedule.denied (exit 3): read the denial and correct the schedule | fix: orch schedule list
  sign.cancelled (exit 3): run it again to review | fix: orch help
  tty.required (exit 3): run it in your terminal | fix: orch help
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
  parse.text (exit 6): orch describe schedule.add
  members.stale (exit 9 retry): retry; the person re-signs | fix: orch status
out: ok {key} schedule.set {id} seq={seq} / next: {next}
