List tickets, newest first.
usage: orch list [--status STATUS] [--mine] [--label LABEL] [--limit N]
  --status STATUS  only this status (backlog|open|in_progress|testing|done|closed)
  --mine  only tickets you hold or are assigned
  --label LABEL  only this label
  --limit N  at most this many [default 20]
more: orch describe list
