    Addons

    {{ on_rows|length }} on · {{ off_rows|length }} available {% if has_custom %}
    {% endif %}

    Addons add pages, tiles and ticket panels to Mission Control. Each card says what it adds and what it needs; switch one on to try it, and off again at any time.

    How switching on works
    • The switch is per workspace and only for you: nobody else's Mission Control changes.
    • Built-in addons come with orch. A custom addon runs only after you trust its exact version, and asks again when its code changes.
    • Addons are never loaded from orchestrator/, so a repository cannot switch one on for you.
