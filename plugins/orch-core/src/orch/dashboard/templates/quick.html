Quick task or ticket

Requirements
none
Plan and task list
none
Human gate
none, you can reopen
Proof
one line, artifacts if useful
Size limit
{{ cfg.max_commits }} commit, {{ cfg.max_files }} files

Past the limit the task is marked "outgrew it" and the agent stops. You make it a ticket, let it finish, or drop it.

How agents pick them up

  • You start one: Open in Mission Control{% if not start.tmux %} (needs the Terminals addon){% endif %} or Open in terminal on its row.
  • No ticket is ready: orch next {% if cfg.next == "first" %}lists quick tasks first{% elif cfg.next == "never" %}leaves them out{% else %}falls through to them{% endif %}.
  • Their ticket is in testing: orch quick near <ticket> lists the ones in the same files.

One at a time, never while their own ticket is still in progress, never one they filed themselves.
