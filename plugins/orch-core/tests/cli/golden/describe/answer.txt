ok describe answer
Answer a question with an option, text, or both.
usage: orch answer Q [--option KEY] [--message TEXT] [--ref REF] [--dry-run]
who: human · emits: question.answered
pre: ticket_exists question_open role_allows user_presence text_clean
args:
  Q  question id
  --option KEY  option key
  -m, --message TEXT  free text
  --ref REF  ticket REF (flag)
  --dry-run  say what would happen, append nothing
errors:
  not_found (exit 2): orch list | fix: orch list
  human_only (exit 3): orch ask or orch wait | fix: orch describe ask
  role.denied (exit 3): ask an owner or maintainer | fix: orch status
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
  parse.text (exit 6): orch describe answer | fix: orch describe answer
  members.stale (exit 9 retry): retry; the person re-signs | fix: orch status
out: ok {key} question.answered {question} seq={seq} / next: {next}
