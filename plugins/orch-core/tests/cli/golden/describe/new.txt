ok describe new
Create a ticket.
usage: orch new TITLE [--type TYPE] [--priority low|medium|high|urgent] [--size SIZE] [--label A,B] [--parent KEY] [--message TEXT] [--file PATH] [--dry-run]
who: agent · emits: ticket.created
pre: workspace_exists grant_valid text_clean
args:
  TITLE  one line, at most 200 characters
  --type TYPE  ticket type (feature|bug|chore|spike|epic) [default feature]
  --priority PRIORITY  priority (low|medium|high|urgent)
  --size SIZE  size (xs|s|m|l|xl)
  --label A,B  labels, comma separated
  --parent KEY  parent ticket key
  -m, --message TEXT  free text
  --file PATH  read the text from PATH, or - for stdin
  --dry-run  say what would happen, append nothing
errors:
  not_found (exit 2): the parent does not exist | fix: orch list
  grant.expired (exit 3): ask the person for a new grant | fix: orch status
  grant.required (exit 3): ask the person to run orch grant, then set ORCH_GRANT | fix: orch status
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
  parse.text (exit 6): orch describe new | fix: orch describe new
out: ok {key} ticket.created {ticket_type} seq={seq} / next: {next}
