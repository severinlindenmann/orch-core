ok describe section.set
Replace one section of the body with text from -m or --file.
usage: orch section set SECTION [--ref REF] [--message TEXT] [--file PATH] [--dry-run]
who: agent · emits: ticket.updated
pre: ticket_exists ticket_open_for_work base_rev_tracked grant_valid text_clean
args:
  SECTION  section id (summary|context|requirements|out_of_scope|plan|decisions|verification|findings|current_state)
  --ref REF  ticket REF (flag); default: your claim
  -m, --message TEXT  free text
  --file PATH  read the text from PATH, or - for stdin
  --dry-run  say what would happen, append nothing
errors:
  not_found (exit 2): orch list | fix: orch list
  grant.expired (exit 3): ask the person for a new grant | fix: orch status
  grant.required (exit 3): ask the person to run orch grant, then set ORCH_GRANT | fix: orch status
  transition.refused (exit 3): orch show --section current_state | fix: orch show
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
  parse.text (exit 6): orch describe section.set | fix: orch describe section.set
  conflict.section (exit 8 retry): orch show --section SECTION, then redo the edit | fix: orch show
out: ok {key} ticket.updated {section} seq={seq} / next: {next}
