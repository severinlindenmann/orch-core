ok describe submit
Move the ticket to testing; every acceptance criterion needs evidence first.
usage: orch submit [REF] [--dry-run]
who: agent · emits: ticket.submitted
pre: ticket_exists session_holds_claim all_ac_have_evidence grant_valid
args:
  REF  ticket REF (DEMO-0043, 43); default: your claim
  --dry-run  say what would happen, append nothing
errors:
  ambiguous_ref (exit 2): name the ticket REF, for example DEMO-0043 | fix: orch status
  not_found (exit 2): orch list | fix: orch list
  grant.expired (exit 3): ask the person for a new grant | fix: orch status
  grant.required (exit 3): ask the person to run orch grant, then set ORCH_GRANT | fix: orch status
  transition.refused (exit 3): orch show --section current_state | fix: orch show
  claim.required (exit 4): orch claim | fix: orch claim
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
  ac.evidence_missing (exit 5): orch artifact add FILE --ac AC1 | fix: orch describe artifact.add
out: ok {key} ticket.submitted testing seq={seq} / next: {next}
