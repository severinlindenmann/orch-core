ok describe task.done
Finish a task: --run runs its verify command and stores the receipt; prints the next task.
usage: orch task done TASK [--run] [--artifact PATH] [--ac AC] [--message TEXT] [--dry-run]
who: agent · emits: task.done,artifact.added
pre: ticket_exists session_holds_claim task_exists session_holds_lease grant_valid text_clean
args:
  TASK  task id (T3 or DEMO-0043/T3)
  --run  run the task's verify command first
  --artifact PATH  evidence file to store
  --ac AC  criterion the evidence is for
  -m, --message TEXT  free text
  --dry-run  say what would happen, append nothing
errors:
  not_found (exit 2): orch list
  grant.expired (exit 3): ask the person for a new grant | fix: orch status
  grant.required (exit 3): ask the person to run orch grant, then set ORCH_GRANT | fix: orch status
  transition.refused (exit 3): orch show --section current_state | fix: orch show
  claim.required (exit 4): orch claim
  lease.held (exit 4): pick another task: orch task next | fix: orch task next
  lease.required (exit 4): orch task start TASK | fix: orch describe task.start
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
  verify.failed (exit 5): fix the cause, then run the task again | fix: orch task next
out: ok {key} task.done {task}[ receipt={receipt}][ artifact={artifact}] seq={seq} / next: {next}
