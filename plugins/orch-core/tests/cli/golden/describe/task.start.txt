ok describe task.start
Take the lease on one task (parallel subagents use ORCH_SESSION=<parent>.<n>).
usage: orch task start TASK [--dry-run]
who: agent · emits: task.started
pre: ticket_exists session_holds_claim task_exists task_lease_free grant_valid
args:
  TASK  task id (T3 or DEMO-0043/T3)
  --dry-run  say what would happen, append nothing
errors:
  not_found (exit 2): orch list | fix: orch list
  grant.expired (exit 3): ask the person for a new grant | fix: orch status
  grant.required (exit 3): ask the person to run orch grant, then set ORCH_GRANT | fix: orch status
  transition.refused (exit 3): orch show --section current_state | fix: orch show
  claim.required (exit 4): orch claim | fix: orch claim
  lease.held (exit 4): pick another task: orch task next | fix: orch task next
  lock.busy (exit 4 retry): retry in a moment | fix: orch status
out: ok {key} task.started {task} seq={seq} / next: {next}
