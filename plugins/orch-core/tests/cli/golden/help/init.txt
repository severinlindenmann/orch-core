Create a workspace here: the genesis event, the workspace key and the instructions.
usage: orch init --prefix PREFIX [--name NAME] [--host] [--dry-run]
  --prefix PREFIX  ticket key prefix, for example DEMO (required)
  --name NAME  your display name
  --host  create it through the running orch host (host.wsk_create, then host.bootstrap): the host keeps the workspace key and serves the workspace; the directory must be empty
  --dry-run  say what would happen, append nothing
more: orch describe init
