List quick tasks (tickets labelled quick) with their commit and file counts; the limits are display only.
usage: orch quick list [--status A,B] [--limit N] [--page TOKEN] [--max-commits N] [--max-files N]
  --status A,B  only these statuses, comma separated (default: all but closed)
  --limit N  at most this many rows [default 100]
  --page TOKEN  the next_page of the previous answer
  --max-commits N  a row is over with more commits than this [default 1]
  --max-files N  a row is over with more changed files than this [default 3]
more: orch describe quick.list
