Read a ticket: the default view, some sections, everything, the log or a diff since an event.
usage: orch show [REF] [--section A,B] [--full] [--log] [--diff] [--since N]
  REF  ticket REF (DEMO-0043, 43); default: your claim
  --section A,B  only these sections, comma separated
  --full  every section
  --log  the event log
  --diff  what changed
  --since N  events after this seq
more: orch describe show
